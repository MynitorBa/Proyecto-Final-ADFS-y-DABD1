# Movent - Agencia de Viajes Digital

Aplicación web full-stack de agencia de viajes desarrollada como proyecto final para el curso de Análisis, Diseño y Fabricación de Sistemas (UNIS 2026).

## Descripción

Movent permite a los usuarios buscar y reservar vuelos, hoteles y paquetes turísticos, integrando múltiples proveedores externos en una sola plataforma.

## Tecnologías

- **Frontend:** Vue 3 + Vue Router + Vite
- **Backend:** Go / Gin
- **Proveedores integrados:** Broom AirLine (.NET), Miku Inn (Java/Javalin)

## Módulos principales

- `Principal.vue` — Página de inicio y búsqueda
- `Reserva.vue` — Selección y confirmación de reservas
- `Checkout.vue` — Proceso de pago
- `MisReservaciones.vue` — Historial y gestión de reservas del usuario
- `ResultadosVuelos.vue` — Resultados de búsqueda de vuelos
- `ResultadosHoteles.vue` — Resultados de búsqueda de hoteles
- `ResultadosPaquetes.vue` — Resultados de paquetes turísticos
