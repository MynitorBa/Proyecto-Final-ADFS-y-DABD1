# Broom AirLine - Documentacion Tecnica Backend

> Backend C# ASP.NET para la aerolinea Broom AirLine. Proyecto final UNIS 2026.

## Tecnologias

- C# / ASP.NET Core
- Oracle Database
- Arquitectura por capas: Controllers, Services, Repositories

## Estructura

- Controllers - Endpoints REST
- Services - Logica de negocio
- Repositories - Acceso a datos
- Models - Entidades
- DTOs - Objetos de transferencia
- Helpers - Utilidades
- Data - Conexion a base de datos
- Program - Punto de entrada de la aplicacion
